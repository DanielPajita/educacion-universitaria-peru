# Comparabilidad entre fuentes

**Estado: pendiente de evaluación.** No unir bases ni elaborar tendencias conjuntas antes de establecer su equivalencia.

| Dimensión | Qué verificar | Decisión actual |
|---|---|---|
| Población | Estudiantes, postulantes, ingresantes, egresados u otra población | Pendiente |
| Unidad | Persona, matrícula, programa, sede o institución | Pendiente |
| Período | Fecha de corte, semestre, año o acumulado | Pendiente |
| Territorio | Residencia, nacimiento o ubicación del establecimiento | Pendiente |
| Instituciones | Cobertura, sedes, cambios de nombre y reorganizaciones | Pendiente |
| Carreras | Clasificaciones y nivel de agregación común | Pendiente |
| Características personales | Definiciones, categorías y valores faltantes | Pendiente |
| Conteos | Duplicados, múltiples matrículas y exclusiones | Pendiente |

Para cada comparación registrar variables de origen, transformación, pérdida de detalle y decisión: comparable, comparable con restricciones o no comparable. Mantener los datos originales sin alterar.

La comparación de cortes separados no representa trayectorias individuales. Las diferencias entre fuentes pueden reflejar cambios de medición o cobertura.
