## Uso

El notebook utiliza Python, pandas, pyreadstat, matplotlib y seaborn. Antes de ejecutarlo, revisar las rutas locales de las fuentes y definir la ruta de los archivos TUNI (`ruta_tuni`). Ejecutar las celdas en orden.

Los archivos originales se conservan en su ubicación local. Las comparaciones entre fuentes requieren revisar las diferencias de cobertura, unidad de observación y definiciones documentadas en el proyecto.
