# Procedimientos

Todavía no hay programas de análisis: se escribirán tras inspeccionar las fuentes y elegir la herramienta adecuada.

1. **Revisión de las bases:** inventario, estructura, unidades, duplicados, faltantes y cobertura.
2. **Preparación por fuente:** limpieza documentada, sin modificar originales.
3. **Armonización de variables:** correspondencias explícitas y categorías comunes justificadas.
4. **Análisis exploratorio:** cuadros y gráficos por fuente; comparaciones solo cuando sean válidas.

Cada programa debe indicar propósito, entradas, salidas, requisitos y orden de ejecución. Debe usar una ruta de proyecto configurable y registrar las exclusiones realizadas.

Verificar unicidad de las llaves y cardinalidad de cada unión; documentar registros emparejados y no emparejados. Contrastar los totales con publicaciones oficiales cuando existan y explicar diferencias.
